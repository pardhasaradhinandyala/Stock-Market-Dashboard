# Stock Market Dashboard

## Project Description
A Python-based interactive dashboard that displays stock market information and historical price trends.

## Features
- Search stocks using ticker symbols
- Latest available stock prices
- Daily price changes
- Historical stock price charts
- Candlestick charts
- Trading volume visualization
- Download historical stock data as CSV

## Technologies Used
- Python 3.13
- Streamlit
- Yahoo Finance (yfinance)
- Pandas
- Plotly

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
streamlit run app.py
```
